AI coaching

Free

Every AI button has a Free option. It opens Claude (app or website) with your answer already filled in. Sign in with your free Claude account and send. Free accounts have a daily limit.

If the message box in Claude is empty, long-press it and paste: the app copies the message for you too.

Paid AI inside the app

Paid · optional

Off unless you set it up. Uses your own Anthropic API key and prepaid credit. Each feedback costs about ₹2–4. The app shows the cost before every use and asks for your PIN.

  • Get a key at console.anthropic.com → API keys. Add a small prepaid credit (for example $5).
  • Keep auto-reload off, so it can never charge more than the credit you added.
  • The key is locked with your PIN and stays only on this phone. It is never uploaded to GitHub.

Install on your phone

In Chrome, open the ⋮ menu and tap Install app or Add to Home screen.

Voice checking uses Chrome's speech service, so it needs internet. Everything else works offline.
